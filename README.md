# MIDWAY PvP

Клиентские моды сервера PvP.

Начиная с MIDWAY 1.0.8 лаунчер автоматически получает все `.pak` из [актуального опубликованного релиза](https://github.com/aleksus95-design/PvP/releases/latest).

Добавляйте PAK в **Assets** текущего релиза. Для обновления заменяйте файл; устаревший PAK с другим именем удаляйте из этого же релиза. Игроки получат изменения при следующей проверке/загрузке перед запуском игры. Новый EXE и ручное редактирование каталога не нужны.

Новый релиз должен содержать полный комплект модов. Сначала загрузите его как Draft, затем опубликуйте как Latest. Draft и Pre-release лаунчер не устанавливает. README, исходники, ZIP и произвольные файлы не устанавливаются как моды.

Размер и SHA-256 каждого PAK проверяются по данным GitHub. При ошибке получения каталога или незавершённой загрузке установленный комплект сохраняется.
